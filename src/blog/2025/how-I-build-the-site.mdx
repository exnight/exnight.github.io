## Why I built this

I have used this repostiory to host my personal website since 2017. This is a rare opportunity to keep my frontend skills up-to-date.

## Tech Stack

- Frontend framework: [Astro](https://astro.build/)
- Styling: [Tailwind CSS](https://tailwindcss.com/)
- CI/CD: GitHub with GitHub Actions
- Hosting: [Github Pages](https://docs.github.com/en/pages)/[Cloudflare Pages](https://pages.cloudflare.com/)

### History

The website has gone through multiple iterations over the years. It evolved from an ancient craft with [React](https://react.dev/) to later [Next.js](https://nextjs.org/docs) and [Tailwind CSS](https://tailwindcss.com/). I played with [Nuxt.js](https://nuxt.com/) briefly but I found it too heavy for my simple needs.

After all these years, especially the blossom of [Vite](https://vite.dev/guide/), it's very tempting to overhaul the whole setup.

### Why Astro?

- A modern static site generator with great DX.
- First-class support for MDX and other formats.

I host my site on GitHub Pages/Cloudflare Pages, which only support static content. I have limited time to maintain my personal projects lately.

Therefore, using Astro keeps things simple and easy to maintain.

## How content works

1. Create a new MDX file and populate frontmatter.
2. Build the project on local and preview.
3. Commit and push to GitHub, done!

## Takeaways

- Clarify your goals then pick the right tools.
- Value your time and focus on what matters.
