## Why I built this

I have used this repostiory to host my personal website since 2017. This is a rare opportunity to keep my frontend skills up-to-date. I want to have a space to share my thoughts and projects. Therefore, I added blogging functionalities.

## Tech Stack

- Frontend framework: [Astro](https://astro.build/)
- Styling: [Tailwind CSS](https://tailwindcss.com/)
- Hosting: [Cloudflare Pages](https://pages.cloudflare.com/)

### History

The website has gone through multiple iterations over the years. It evolved from an ancient craft with [React](https://react.dev/) to later [Next.js](https://nextjs.org/docs) and [Tailwind CSS](https://tailwindcss.com/). I played with [Nuxt.js](https://nuxt.com/) briefly but I found it too heavy for my simple needs.

After all these years, especially the blossom of [Vite](https://vite.dev/guide/), it's very tempting to overhaul the whole setup.

### Why Astro?

- A modern static site generator with great DX.
- First-class support for [MDX](https://mdxjs.com/) and other formats.

I host my site statically on Cloudflare Pages, with limited time to maintain it. Using Astro keeps things simple and easy to maintain.

## How content works

1. Create a new MDX file and populate frontmatter.
2. Build the project on local and preview.
3. Commit and push to GitHub, done!

MDX supports a variety of components, for example,

a math forumla:

$$
\begin{array}{lr}
F = ma & \text{(1)} \\
E_k = \frac{1}{2}mv^2 & \text{(2)}
\end{array}
$$

or a code block:

```bash
npm install
npm run dev
```

## Takeaways

- Clarify your goals then pick the right tools.
- Value your time and focus on what matters.
