## Why I built this

I have used this repostiory to host my personal website since 2017. This is a rare opportunity to keep my frontend skills up-to-date. I also want to have a space to share my thoughts and projects. Therefore, I added a blog recently.

## Tech Stack

The website has gone through multiple iterations over the years. It evolved from an ancient craft with [React](https://react.dev/) to later [Next.js](https://nextjs.org/docs) and [Tailwind CSS](https://tailwindcss.com/). I played with [Nuxt.js](https://nuxt.com/) briefly but I found it too heavy for my simple needs.

After all these years, especially the blossom of [Vite](https://vite.dev/guide/), it's very tempting to overhaul the whole setup. I adopted [Astro](https://astro.build/) as it's a modern static site generator with great DX. It also provides first-class support for [MDX](https://mdxjs.com/) and other formats.

I used to host my site on [GitHub pages](https://docs.github.com/en/pages), but I was playing around with [Cloudflare Pages](https://pages.cloudflare.com/) lately. Given I have limited time to maintain the site, using Astro help keep things simple and easy to maintain.

## How content works

I can first create a new MDX file and populate frontmatter. Next, I build the project on local and preview. Lastly, I commit and push to GitHub, done!

MDX supports a variety of components, for example,

a math forumla:

$$
\begin{array}{lr}
F = ma & \text{(1)} \\
E_k = \frac{1}{2}mv^2 & \text{(2)}
\end{array}
$$

or a code block:

```bash
npm install
npm run dev
```

## How about AI agents

I have to admit that I'm never a good designer. Fortunately, I found ["Impeccable"](https://impeccable.style/). Combining it with [Copilot CLI](https://github.com/features/copilot/cli) and various models, I revamped the visuals to something better than what I can produce.

## Takeaways

Clarify your goals then pick the right tools. Value your time and focus on what matters.
