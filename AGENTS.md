This is a personal website repository. Find details in `README.md`.

## Development Protocol

- Perform changes in batch
- Ask user to start the dev server manually on port 3000 if there isn't one.
- Avoid multiple running dev server instances.
- Run `npm run test` after all changes in a batch are completed, fix broken tests.
- Run `npm run build` after all changes in a batch are completed, fix broken builds.
